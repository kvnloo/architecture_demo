# Architecture Portfolio Universe Website

This is a Next.js website showcasing the Architecture Portfolio Universe - a collection of AI-generated architectural visualizations.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Components**: shadcn/ui with Radix UI primitives
- **Styling**: Tailwind CSS v3
- **Deployment**: GitHub Pages (Static Export)

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Features

- Dark theme optimized color palette
- Responsive image galleries
- Static site generation for GitHub Pages
- Custom architectural portfolio showcase

## Color Palette

- Background: #0a0a0a (deep charcoal)
- Surface: #1a1a1a (elevated surfaces)
- Primary (Gold): #d4af37 (brass fixtures)
- Secondary (Walnut): #8b7355 (wood tones)
- Accent (Slate): #4a5568 (UI elements)

## Deployment

The site automatically deploys to GitHub Pages when changes are pushed to the main branch via GitHub Actions.
